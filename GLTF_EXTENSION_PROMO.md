# NCrews GLTF/GLB Shell Extension

## Transform Your 3D Workflow with Instant Visual Previews

Browse your 3D models as easily as browsing photos. **Install once, preview forever.**

---

## Overview

The **NCrews GLTF/GLB Shell Extension** brings professional 3D model visualization directly into Windows Explorer. No more guessing which file contains the model you need - see beautiful, high-quality thumbnail previews of your GLTF and GLB files instantly, just like viewing photos.

Supports both `.gltf` (JSON format) and `.glb` (binary format) files with full material, texture, and geometry visualization.

---

## Key Features

### Automatic Thumbnail Generation
Every GLTF/GLB file displays a rendered 3D preview in Windows Explorer

### Right-Click Context Menu
Generate custom preview images on demand with configurable settings

### Windows 11 Compatible
Built with the latest Windows compatibility standards

### Lightning Fast
Optimized rendering powered by Open3D delivers crisp previews in seconds

### Professional Quality
High-resolution output suitable for presentations and documentation

### Seamless Integration
Works natively with Windows Explorer - no separate viewer needed

## Installation

1. Download the installer from the [Releases](../../releases) page
2. Run the installer as Administrator
3. Restart Windows Explorer
4. Your GLTF/GLB files now show thumbnail previews automatically
